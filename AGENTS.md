# AGENTS.md

## Project

Ash Mohaghegh Personal Website

## Instructions for AI

- Read `PRD.md` before making major changes.
- Use plain HTML and CSS.
- Keep the website simple and understandable.
- Use semantic HTML where appropriate.
- Preserve existing personal content unless specifically asked to change it.
- Use relative paths for local files.
- Keep navigation clear and consistent.
- Make the site responsive for desktop and mobile.
- Do not add frameworks unless specifically requested.
- Avoid unnecessary JavaScript.
- Check that links and images work after changes.
- Keep code readable and easy to explain.

## Design Direction

The website should feel:

- Professional
- Personal
- Clean
- Modern
- Easy to navigate

Avoid a generic AI-generated appearance or unnecessary visual effects.

## Responsive Design

Make sure:

- Text fits on mobile screens
- Images resize correctly
- Navigation remains usable
- Cards stack when necessary
- There is no horizontal scrolling

## AI Responsibility

AI can help generate, explain, debug, and improve code, but all output should be reviewed and understood before it is accepted.
