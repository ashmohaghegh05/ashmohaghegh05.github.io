# Personal Website PRD

## Project

Ash Mohaghegh Personal Website

## Purpose

Create a personal website that introduces me, explains my academic and professional interests, and provides access to my OIM3690 coursework and Lightning Talk.

## Audience

The website is intended for:

- Classmates
- Instructors
- Graduate programs
- Professional contacts
- Potential employers

## Goals

The website should:

- Introduce who I am
- Explain my academic background
- Present my interests in technology, entrepreneurship, urban planning, and city design
- Link to my OIM3690 course website
- Provide access to my Lightning Talk
- Work well on desktop and mobile devices

## Main Content

### About Me

Introduce me as a senior at Babson College concentrating in Technology Entrepreneurship.

Explain my interest in graduate study related to urban and city planning and design.

### Interests

Present my main interests:

- Urban Planning
- Technology
- Entrepreneurship

### Education and Future Goals

Explain how my Babson education and entrepreneurial background connect to my future interest in urban planning and design.

### OIM3690

Include a link to my OIM3690 Web Development with AI course website.

### Lightning Talk

Provide a direct link to my Lightning Talk PDF.

## Design Direction

The site should feel:

- Professional
- Personal
- Clean
- Modern
- Easy to read
- Easy to navigate

The design should avoid unnecessary complexity and should remain understandable enough for me to explain the HTML and CSS.

## Technical Requirements

- Plain HTML and CSS
- Semantic HTML
- Responsive design
- Mobile-friendly layout
- Relative links for local files
- Accessible image alt text
- Working links
- GitHub Pages deployment

## Responsive Design

The website should adjust for smaller screens.

On mobile:

- Navigation links should remain readable
- The profile image should fit the screen
- Content should stack vertically when necessary
- Interest cards should stack vertically
- No horizontal scrolling should occur

## Success Criteria

The website is successful when:

- The homepage loads correctly
- The profile photograph displays
- Navigation works
- The OIM3690 link works
- The Lightning Talk PDF opens
- The page is readable on a phone
- The website is deployed through GitHub Pages
